# mixer-broadcaster

**Want to meet your friends in a shared 3D room?**

Walk in late and everyone should already be there, not missing until they move.

The relay sends a late joiner the last pose of every entity in the room, and it forwards your pose to the others as one 100-byte packet.

For developers: run `mix deps.get` and `mix test`, then read `docs/guide.md`. `docs/status.md` holds the status.
